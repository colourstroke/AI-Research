AI-Research

Purpose

A personal learning and research workspace for Agentic AI.

This repository documents my learning process and develops reusable AI-assisted research workflows for biomedical, environmental health, and public health research.

Learning Roadmap

* W1: Agent foundations, Markdown, YAML, AGENTS.md, and Git
* W2: Tools and interfaces — API, CLI, GUI, ACI, and JSON
* W3: Agent Skills and SKILL.md
* W4: Model Context Protocol (MCP)
* W5: GitHub Pages and automated workflows

Research Applications

* Biomedical literature review
* Environmental exposure science
* Environmental aerosols and air pollution
* Toxicology and epidemiology
* Citizen science and environmental monitoring
* Public health and healthcare accessibility
* Science communication and education

Repository Structure

* 01_Foundations/ — Core concepts and technical foundations
* 02_Agent_Platforms/ — AI agent platforms and tools
* 03_Skills/ — Reusable agent skills and instructions
* 04_MCP/ — Model Context Protocol and external integrations
* 05_Research_Workflows/ — Reproducible AI-assisted research workflows
* 06_Templates/ — Reusable research and documentation templates
* 99_Notes/ — Learning notes and miscellaneous records

Repository Principles

1. Keep learning notes organized and reusable.
2. Distinguish established evidence, preliminary findings, hypotheses, and assumptions.
3. Record traceable sources for scientific claims.
4. Never fabricate scientific references or research findings.
5. Protect personal, patient, and confidential research data.
6. Document workflows so they can be reproduced and evaluated.
7. Use AI as a research assistant, not as a substitute for scientific judgment.
